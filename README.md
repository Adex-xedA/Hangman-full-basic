It's a Hangman game!
Features: 
  -Categories
  -A scoring system
  -Leaderboards
  -A secret extra chance to keep half of your score 

How to install:
 Download the content and put everything in a folder.
 Run the hangman.exe file.
 Windows will promt that the program is not licensed, press more info and run anyway.

This game is made in Python as an exercise to learn more coding. It is using basic programming.
